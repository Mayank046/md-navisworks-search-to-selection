# Changelog

## 1.0.0 — 2026-11-05

Initial public release.

- Converts Navisworks Search Sets to Selection Sets in one click (one set, many sets, folders, or all).
- Keeps folder structure; never changes or deletes the original search sets.
- Options: output folder, write-beside with `(Sel)` suffix, name suffix, overwrite, skip empty results, cancel mid-run.
- No-admin per-user installer and a portable zip for Navisworks Manage and Simulate 2017–2027.
- Core unit tests on a fake Sets window (no Navisworks required to run them).
